# NovaTech

Site web vitrine de NovaTech, une entreprise fictive, réalisé dans le cadre du TP final du module Versionning et Git.

## Contenu du site

Le site est construit progressivement et contiendra les pages suivantes :

- Accueil
- Présentation de l'entreprise
- Services
- Contact
- Mentions légales

## Lancer le projet

Aucune installation n'est nécessaire : ouvrez `index.html` dans un navigateur.
